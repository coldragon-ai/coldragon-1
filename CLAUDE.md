## Next.js 16 caveat

This is Next.js 16 with the App Router. Per `AGENTS.md`, APIs and conventions differ from earlier versions — consult `node_modules/next/dist/docs/01-app/` before writing framework code rather than relying on prior knowledge. The `nextjs-agent-rules` block in `AGENTS.md` is regenerated by `next dev`; commit it alongside changes to keep the tree clean.

## Architecture

Single-page marketing/RSVP site for a 국가인공지능전략위원회 지원단 networking event. The entire page is `src/app/page.tsx`.

- **`src/` layout with `@/*` alias** → `./src/*` (see `tsconfig.json`). App Router lives in `src/app/`.
- **`src/app/page.tsx`** is a `"use client"` component. All event content — `EVENT`, `PROGRAM`, `NOTICES` — is defined as module-level constants at the top of the file; edit those to change dates, venue, schedule, or notices. Unconfirmed values are intentionally left as placeholders (`00:00`, `○○`).
- **The form is UI-only by design.** `handleSubmit` calls `preventDefault()` and `console.log` — no fetch, no API route, no server action. Do not add a backend unless explicitly asked; when asked, that is the point to introduce a route handler or server action.
- **`src/app/layout.tsx`** sets `metadata` (page title/description) and loads Geist / Geist Mono via `next/font/google`. It uses the Next 16 typed `LayoutProps<"/">` signature.

## Styling

Tailwind CSS v4, wired through `postcss.config.mjs` (`@tailwindcss/postcss`). There is **no `tailwind.config.js`** — theme tokens and font variables are declared in `src/app/globals.css` via `@theme inline` and `@import "tailwindcss"`.

Convention for this project: public-sector UI uses a **blue palette** (`blue-700`/`blue-800` for primary actions and headers, `slate` for text/surfaces). Dark mode is handled with `dark:` variants driven by `prefers-color-scheme`.
